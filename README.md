# Sure Music Studio · Android 更新

这里提供 Music Studio 的 Android 安装包、更新说明、更新清单及对应源码包。开发仓库保持私有。

从 [最新版本](https://github.com/Sure-Will/Sure-Music-Studio-Releases/releases/latest) 下载 APK。要求 Android 10 或更新版本。已安装带更新器的版本后，可在 **设置 → 应用更新** 中检查、下载，并由 Android 系统确认覆盖安装。

应用支持歌曲下载、公开视频保存、音频提取与小红书图片保存。歌曲、图片、视频分别设置保存目录；覆盖升级保留设备上的歌单、任务记录和配置。公开包不内置个人歌单或访问令牌。

每个正式版本同时提供：

- `Sure-Music-Studio-<版本>+<版本码>.apk`
- `update.json` 与 SHA-256 校验文件
- `Sure-Music-Studio-<版本>+<版本码>-source.zip`，包含该 APK 的应用源码、构建文件、GPL 依赖对应源码和许可说明

应用源码按 GPL-3.0 提供，第三方组件保留各自许可；仓耳今楷字体属于独立授权资产，官方允许个人非商业免费使用，商业使用需另行授权，详见源码包内字体说明。源码包不包含签名私钥、访问令牌、Git 历史或个人歌单。

更新器仅接受此仓库的版本文件，安装前核对包名、版本、大小、SHA-256 和固定发布签名。有媒体任务运行时先等待任务完成，再安装更新。
